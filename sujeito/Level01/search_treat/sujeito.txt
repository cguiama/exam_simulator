Assignment name  : search_treat
Expected files   : search_treat.c
Allowed functions: write, exit
--------------------------------------------------------------------------------

Escreva um programa chamado search_treat que receba 3 argumentos.
O primeiro argumento é uma string na qual as substituições serão feitas.
O segundo argumento é a letra a ser substituída.
O terceiro argumento é a letra substituta.

O programa deve substituir todas as ocorrências da primeira letra pela segunda na string original,
exibindo o resultado seguido de uma nova linha (\n).

Se o segundo argumento não for um único caractere (por exemplo, "ab"),
o programa não faz substituições e apenas exibe a string original + \n.
Se o número de argumentos não for exatamente 3, exiba apenas uma nova linha.

Exemplos:
$> ./search_treat "gato come racao" "a" "o" | cat -e
goto come rocoo$
$> ./search_treat "cao" "a" "u" | cat -e
cuo$
$> ./search_treat "cao" "a" "uu" | cat -e
cao$
$> ./search_treat | cat -e
$
